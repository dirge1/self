# 任务奖励 App

一个简单的本地网页应用：
- 添加日常任务（设置完成后可获得的积分）
- 完成任务自动累计积分
- 设置奖励并用积分兑换
- 默认自动保存到浏览器 `localStorage`
- 支持导出/导入 JSON 文件（保存到你电脑上）

## 给小白的最简单运行方法（一步步照做）

### 第 1 步：打开终端
- **Mac**：打开 `Terminal`
- **Windows**：打开 `PowerShell` 或 `CMD`
- **Linux**：打开 `Terminal`

### 第 2 步：进入项目目录
假设你的项目在 `/workspace/self`：

```bash
cd /workspace/self
```

### 第 3 步：启动本地网页服务

```bash
python3 -m http.server 4173
```

你会看到类似这行提示，表示启动成功：

```text
Serving HTTP on 0.0.0.0 port 4173
```

> 这时先不要关终端，服务正在运行。

### 第 4 步：打开浏览器访问
打开任意浏览器（Chrome / Edge / Safari / Firefox），在地址栏输入：

- <http://localhost:4173>

就能看到 App 页面。

### 第 5 步：停止服务
回到刚才那个终端窗口，按：

- `Ctrl + C`

## 你提到的两个命令是什么意思？

### `node --check app.js` 是什么？

这是**语法检查命令**，只检查 `app.js` 有没有语法错误：
- ✅ 通过：通常不会输出任何内容，直接返回
- ❌ 失败：会显示第几行有语法问题

它**不会启动 App**，也不会打开网页。

### `python3 -m http.server 4173` 是什么？

这是**启动本地网页服务器**的命令，意思是：
- 用 Python 开一个本地服务
- 端口是 `4173`
- 让浏览器可以通过 `http://localhost:4173` 打开你的网页

## 一键运行（可选）

如果你不想每次手敲命令，可以执行：

```bash
./run_app.sh
```

效果和 `python3 -m http.server 4173` 一样。

## 数据会不会丢？

默认情况下，数据存在浏览器的 `localStorage`，通常不会因为刷新页面而丢失。以下情况可能丢失：
- 你手动清理了浏览器站点数据
- 使用了无痕模式并关闭窗口
- 更换浏览器或更换设备

如果你想把数据真正存成“电脑文件”：
1. 在页面点击 **导出到文件**
2. 会下载一个 JSON 文件到你的电脑
3. 之后可用 **从文件导入** 恢复

## 常见问题

### 1) 提示 `python3: command not found`

可以试试：

```bash
python -m http.server 4173
```

### 2) 4173 端口被占用

换一个端口，比如 8080：

```bash
python3 -m http.server 8080
```

然后打开 <http://localhost:8080>。
